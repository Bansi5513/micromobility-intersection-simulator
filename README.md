# Micromobility Intersection Simulator

A Unity simulation of a Los Angeles style city where an e-scooter rider crosses intersections with traffic signals and moving cars. The simulator measures rider safety using time to collision and saves every run to a CSV file for analysis.

## Demo
[Watch the demo video](micromobility_simulator_demo.mp4)

## Features
- 5 x 5 city grid with boulevards, green bike lanes, crosswalks, traffic signals, towers, parks, palm trees, and hills, all generated from code
- Traffic signals that cycle through green, yellow, and red at every intersection
- Background cars that follow waypoints, stop at red and yellow lights, and keep a gap to the car ahead
- Three scenarios loaded from a JSON file:
  - Right hook with a fast overtaking car
  - Right hook with a slower car ahead
  - Baseline with no conflict
- Live display of speed, time to collision, minimum time to collision, near miss detection, and red lights run
- Run ends when the rider crashes or leaves the road
- Data logger that records the rider and nearest car ten times per second, with one CSV per run and a summary file for all runs

## Controls
- W / S: speed up and brake
- A / D: steer
- C: change camera
- 1 / 2 / 3: choose scenario
- R: restart

## Project Structure
- `Assets/Scripts`: rider controller, car AI, traffic lights, scenario manager, data logger, and city layout
- `Assets/Editor/SceneBuilder.cs`: editor tool that builds the whole city scene (menu: Micromobility > Build City Scene)
- `Assets/Resources/scenarios.json`: scenario settings such as car speed, traffic level, and green light time
- `Packages/manifest.json`: Unity packages used by the project

## Built With
Unity 6.3 LTS, C#, Universal Render Pipeline, Input System

## How to Run
1. Create a new Unity 6.3 project using the Universal 3D template
2. Copy the Assets folder from this repository into the project
3. In the menu bar, click Micromobility > Build City Scene
4. Open Assets/Scenes/City.unity and press Play

The scene and materials are generated by the scene builder, so they are not stored in this repository.
